\subsubsection{Класс Tabel}

Данный класс используется для управления столами, позволяя пользователю выбрать категорию и производить взаимодействие с заказами. Класс Tabel включает в себя обработку информации из таблиц базы данных и создание графического интерфейса, используя модули, представленные в таблице \ref{class:table_class_table}.

\begin{xltabular}{\textwidth}{|p{6cm}|X|}

	\endfirsthead

\subsection{Системное тестирование программно-информационной системы управления ресторанным бизнесом}
Для проверки работоспособности программы следует провести системное тестирование разработанного функционала пользовательского взаимодействия. Результаты тестирования представлены снимками экрана. 

На рисунке ~\ref{inwindow:image} изображена страница авторизации, которая открывается сразу после запуска приложения. При вводе пароля должность <<Официант>>, открывается окно с выбором столов, (см. риунок~\ref{rptabels:image}). После выбора номера стола и нажатия на одноимённую кнопку  откроется страница с заказом(см. риунок~\ref{rpzakaz:image}). Если заказ выбранного стола уже был отпечатан в системе, то таблица будет заполнена его данными, в противном случаи откроется новый пустой заказ. Далее нужно выбрать категорию меню и слева появятся названия блюд. При нажатии на кнопку блюда оно добавится в таблицу заказа. При успешном создании нового заказа нужно нажать кнопку <<Печать>> или <<Оплата>>. При нажатии на вторую кнопку, заказ автоматически получит статус <<Напечатан>>. Далее происходит переход страницу оплаты (см. риунок~\ref{rpoplatazakaza:image}), где пользователь может выбрать её тип, внести нужную сумму и нажать на кнопку <<Оплатить>>, после чего окно закроется. На рисунке ~\ref{rpoldzakaz:image} представлено окно просмотра уже закрытых заказов. Можно использовать поиск по номеру заказа или фильтрацию по датам.
